## Data Cleaning and Transformation

# Perform the following tasks using the data in the "Dataset" sheet.

# 1. Handling Missing Values

- Check for missing values in the "Price" column and determine how to handle products with missing price information.
- If any products have missing categories, propose a suitable strategy to impute or handle these missing values effectively.

# 2. Correcting Inconsistent Data

- Identify inconsistent text formats in the "Product Name" column.
- Identify typos in the "Category" column.
- Use Find and Replace to standardize text formats in the "Product Name" column and correct typos or misspellings in the "Category" column.

# 3. Removing Duplicates

- Identify duplicate rows in the dataset based on the entire row and remove them, if any.

# 4. Splitting and Merging Data

- Split the "Product ID" column into two separate columns: "Manufacturing Date" and "Country Code".
- Remove any unnecessary characters, if present.
- Merge the "Brand Name" and "Product Name" columns into one column named "Product Brand".

 # 5. Number Formatting

- Format the "Price" column as currency.
- Format the "Manufacturing Date" column to display dates in the "DD-MM-YYYY" format.

# 6. Conditional Formatting

- Apply data bars or color scales using conditional formatting to the "Price" column.
- Create a custom conditional formatting rule in the "Category" column to highlight cells where the category is "Electronics".
